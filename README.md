# Build a Travel Agency Page

Build an app that is functionally similar to the example project. Try not to copy the example project exactly; give it your own personal style.

## Objective

Fulfill the user stories below and get all the tests to pass to complete the lab.

## User Stories

1. You should have a `DOCTYPE` declaration.

2. You should have an `html` element with `lang` set to `en`.

3. You should have a `head` element containing:
   - a `meta` void element with `charset` set to `utf-8`
   - a `title` element with the text `Travel Agency Page`

4. You should have a `meta` tag in your `head` element that contains a short description of your website for SEO.

5. You should have an `h1` element to present your travel destinations. It should be the only `h1` element on your page.

6. You should have a paragraph below the `h1` element introducing the travel opportunities.

7. You should have an `h2` element with the text `Packages`.

8. You should have a `p` element briefly introducing the various packages.

9. You should have an unordered list element with two list items. The two list items should have the text:
   - `Group Travels`
